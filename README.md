# AI Brochure Generator

An AI-powered brochure generator built with:

- Python
- Streamlit
- LangChain
- Mistral AI
- Tavily Search
- BeautifulSoup

## Features

- Website scraping
- AI-generated marketing brochure
- Structured output
- Modern Streamlit UI

## Installation

```bash
pip install -r requirements.txt
```

Create a `.env` file:

```
MISTRAL_API_KEY=your_key
TAVILY_API_KEY=your_key
```

Run:

```bash
streamlit run app.py
```
